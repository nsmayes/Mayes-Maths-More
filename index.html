Install it once, then use it offline

Open this page on the device your child will use, install the app, and open it once while you are online. Everything it needs is then saved on the device, and it works with no internet connection. When you are online it updates itself.

Laptop or desktop: Chrome or Microsoft Edge
  1. Click Install on this device above, or the install icon at the right of the address bar (a screen with a down arrow).
  2. Click Install. The app opens in its own window and appears in your Start menu, Dock or app list.
Android phone or tablet: Chrome
  1. Tap Install on this device above, or open the ⋮ menu and tap Install app (or Add to Home screen).
  2. Tap Install. Pip’s icon appears on your home screen.
iPad or iPhone: Safari

iPhones and iPads do not have an install button: you add the app to the Home Screen yourself. It only takes a minute.

  1. Open this page in Safari (or Chrome). If it opened inside another app, such as WhatsApp, Facebook or email, first choose Open in Safari from that app's menu (⋯ or the compass icon).
  2. Tap the Share button (a square with an arrow pointing up). It is at the bottom of the screen on iPhone, at the top on iPad. If you cannot see it, tap the ⋯ button first.
  3. Scroll down and tap Add to Home Screen. If you see Open as Web App, leave it switched on. Then tap Add.
  4. Open the app from Pip's icon on the Home Screen once while you are online, so it can save itself on the device. After that it works with no internet.
  5. Always open it from that icon: progress saved there is kept separately from Safari.
Mac: Safari
  1. In Safari, choose File → Add to Dock.
  2. Open it from the Dock once while you are online.
Firefox

Firefox on a computer cannot install apps, but it still keeps the app working offline: bookmark the app and open it once while you are online. Or use Chrome or Edge to install it.

Pip reads questions aloud using the device’s own voice, which you can choose in the app’s sound settings.

Privacy

Mayes Maths & More has no accounts, no adverts, no tracking and no analytics. Children’s names, answers and progress are saved only on your device, in the browser. The app never sends them anywhere.

The only time the device contacts this website is to download or update the app. Like any website, the hosting service may keep standard technical logs of those downloads. Nobody can see your child’s progress except people using your device.

Keeping progress safe

Because progress stays on your device, it is lost if the device is lost or the browser’s data is cleared. In Grown-ups’ area → Settings and back-up you can download a backup file now and then, and restore it on any device.

Each child can have a secret 3-number code so that brothers and sisters don’t play as each other by accident. The grown-ups’ area has its own PIN.
